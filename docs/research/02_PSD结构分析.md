# moca.psd 结构解析与"自动立绘差分"可行性报告

> 生成时间: 2026-10-19 · 分析者: psd-analyst · 原始素材只读，所有产物在 `_work/psd/`
> 解析工具: `psd_tools 1.25.0`（cp313 wheel，vendored 在 `_work/psd/vendor/`，无需安装到 site-packages）

---

## 0. 一句话结论

**可以完全用 Python 离线合成，而且很快——但不要每帧调用 `psd_tools.composite()`。**
moca.psd 是"纯像素层"结构（无智能对象 / 无文字 / 无调整层 / 无 clipping mask / 无图层蒙版 / 无 Layer Comps），
所以 ① 用 psd_tools 一次性合成一张"隐藏口型+眼睛"的底图，② 每帧只把口型/眼睛小图贴上去，
实测 **0.028 s/帧 @1080p**（numpy 贴图 + ffmpeg 管道），**5800 帧全片 ≈ 2.7 分钟**。
反之，直接 `psd.composite()` 每帧重合成 = **8.1 s/帧 → 5800 帧 ≈ 13 小时**，不可行。

## 7. 合成实测：能不能用 Python 离线合成？

**能，且是 1:1 可复现的**（无 Photoshop 专有特性）：

- ✅ 全部 159 个图层都是 `kind=pixel`
- ✅ **0 个 clipping mask**、**0 个图层蒙版** —— 不存在"必须由 PS 解释"的蒙版树
- ✅ 无智能对象、无文字层、无形状/矢量层、无调整层（因此不需要 aggdraw，也不涉及滤镜/调整算法还原）
- ⚠️ 有 1 个 MULTIPLY 混合层（`闇`，默认隐藏）和 1 个 PASS_THROUGH 组（`前パーツ`）——psd_tools 支持；只要默认状态不激活它们，我们的贴图管线就不受影响
- ⚠️ `composite(apply_icc=True)`（默认）会做 ICC 色彩转换，若要和 Photoshop 像素级对齐，可对比 `apply_icc=False`；本 PSD 是 sRGB，差异可忽略
- ✅ 无 Layer Comps → **没有现成的表情组合可复用**，必须自己定义状态表（推荐 JSON，见 §9）

## 8. 性能实测（本机，Windows，2480×3500）

| 方案 | 单帧耗时 | 5800 帧（242s@24fps） | 评价 |
|---|---|---|---|
| `psd.composite()` 每帧重合成（真合成） | **8.10 ~ 8.38 s** | **≈ 13.1 小时** | ❌ 不可行 |
| `psd.composite(viewport=脸区 620×500)` | 0.47 ~ 0.62 s | ≈ 48 分钟 | ⚠️ 可用但慢，仅适合"每帧都换状态"的兜底 |
| 预导出 base + PIL 贴图 + 存全分辨率 PNG | 0.183 s | ≈ 18 分钟 | ✅ 简单可靠 |
| 预导出 base + PIL 贴图 + ffmpeg 管道(1080p x264) | 0.066 s | ≈ 6.4 分钟 | ✅ |
| **预导出 base + numpy 贴图 + ffmpeg 管道(1080p)** | **0.0284 s** (35 fps) | **≈ 2.7 分钟** | ⭐ 推荐 |
| 参考：ffmpeg 编码下限（喂现成帧） | 0.0135 s (74 fps) | ≈ 1.3 分钟 | — |

一次性成本：
- 打开 PSD 0.17 s；**真合成 base 一次 8.1 s**；导出所有差分 patch 11 层共 **0.005 s**
- 内存：打开后 RSS 68 MB → composite 后 145 MB → 峰值 261 MB；base RGB 26 MB / 全画布 RGBA 35 MB（可常驻缓存）
- 单帧分解：`base_rgb.copy()` 6.5 ms + 贴口型+贴眼 4.2 ms + `tobytes()` 5.5 ms + ffmpeg 编码 13.5 ms

> 关键坑：`psd.composite()` **有一个"快路径陷阱"** —— 只要你没改过任何图层属性（`psd.is_updated()` 为 False），
> 它会直接返回 PSD 内部保存的**合并预览图**（1.3 s），而不是按图层合成；一旦你设置过 `layer.visible`
> （setter 会自动 `psd.mark_updated()`），后续 `composite()` 才是真合成（8 s）。
> 想强制真合成就传 `ignore_preview=True`。这也解释了为什么"看起来很快"的合成其实是读预览图。

## 9. 离线渲染架构建议（预导出 PNG 序列 + 贴图，不要每帧合成）

```text
一次性（约 10 秒）:
  1. 打开 moca.psd
  2. 关掉 0.3.1(口组) + 0.3.2.0.2(当前可见的睁眼变体组)   ← 基准底图
  3. base = psd.composite(ignore_preview=True).convert("RGB")   ← 8.1s，导出 base.png
  4. 对每个差分候选层: L.topil() + L.offset  →  patches/mouth_a.png, eyes_closed_neutral.png ...
     （全部 11 个只花 0.005s，可全部预导出，也可只导出用到的）

每帧（约 28 ms）:
  frame = np.copy(base_rgb)
  frame = alpha_blend(frame, mouth_patch)     # 口型
  frame = alpha_blend(frame, eye_patch)       # 睁/闭眼（可留空）
  ffmpeg.stdin.write(frame.tobytes())         # rawvideo rgb24 → scale=1080:-2 → libx264

视频: 24fps, 5800 帧, 1080×1524, 全片 ≈ 2.7 分钟
```

**基准状态配置建议**（PSD 自带可见性不可靠，必须显式声明）：

```json
{
  "canvas": [2480, 3500],
  "base_hidden_groups": ["0.3.1", "0.3.2.0.2"],
  "mouth": {
    "a": "0.3.1.19.4", "i": "0.3.1.19.3", "u": "0.3.1.19.2",
    "e": "0.3.1.19.1", "o": "0.3.1.19.0", "n": "0.3.1.1", "closed": "0.3.1.3"
  },
  "eyes": {
    "open":  "0.3.2.0.2.9",
    "blink": "0.3.2.1.9",
    "smile": "0.3.2.1.8",
    "cry":   "0.3.2.1.6"
  },
  "brows": { "neutral": "0.3.3.0", "angry": "0.3.3.1" },
  "extra_state": { "0.3.3": "0.3.3.0", "0.3.0.0": "0.3.0.0.0" }
}
```

> 注意 `0.3.3` 默认是 `怒り`（怒眉），做中性唱歌表情要显式开 `0.3.3.0 通常`。

## 10. 推荐结论：直接 psd-tools 合成 vs 预导出 PNG 序列

| | 直接 `psd_tools.composite()` 合成 | **预导出 base + 差分 patch（推荐）** |
|---|---|---|
| 单帧耗时 | 8.1 s | 0.028 s |
| 5800 帧 | ~13 小时 | **~2.7 分钟** |
| 实现复杂度 | 低 | 中（一次性导出 + 每帧贴图） |
| 灵活性 | 任意改层/换装/换表情 | 适合固定基准 + 口型/眼差分；换装需重导 base |
| 风险 | 几乎无 | 低（层都是纯像素、无 mask） |

**结论**：做"从 Synthesizer V 人声轨自动选口型/眼睛差分"这个工具，**用预导出路线**：一次性导出 base 与差分 patch，
运行时只做 RGBA 贴图 + ffmpeg 编码。若将来要做"整身换装"或"任意表情组合"，再对每组基准状态各导出一次 base 即可
（每次约 8 s，仍可接受）。**不建议**每帧调用 `psd_tools.composite()`。

## 12. 已知坑 / 注意事项（给实现者）

1. **`composite()` 快路径**：未修改图层时返回内嵌预览图；改 `visible` 后才是真合成（8 s）。需要真合成时传 `ignore_preview=True`。
2. **组可见性不级联**：设 `layer.visible=True` 不会自动打开父组；`口` 的 `あいうえお` 组、`閉じ` 组默认都是关的。
3. **bbox 顺序**：`psd_tools` 用 `(left, top, right, bottom)`；PSD 文件原始 layer record 是 `(top, left, bottom, right)` —— 自己解析时极易搞错（Lead 早期版本就踩了这个坑）。
4. **`layer.topil()` 拿的是"该层自己的像素"**（bbox 大小，含 alpha），组对象上调用会返回组内可见内容的合成图；贴图要用单层 + `layer.offset`。
5. **默认可见性不可信**（big/small 有 10 处不同），要显式维护状态配置。
6. **眉毛默认是"怒り"**，不是中性；否则每帧都怒眉。
7. **`う` 只有 31×26 px**，视觉上接近点；`ん` 只有 34×11 px（一条线）。
8. 若之后要合成**文字/形状/智能对象**的 PSD，需要装 `aggdraw` 并使用 `psd-tools[composite]`；本 PSD 不需要。
9. 全片 5800 帧建议**先把口型/眨眼时间轴算成索引数组**，再进渲染循环，避免每帧做选择逻辑。
10. 素材授权（`readme.txt`）：仅限非商用/同人向、二次配布禁止 —— 工具自用没问题，别把差分图/PSD 再分发。
